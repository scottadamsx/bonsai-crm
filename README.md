# BONSAI CRM

Lightweight sales CRM for solo operators. Reverse-engineered from Close CRM, stripped to what actually matters.

## What it does
- Contact management (import from prospect lists)
- Pipeline with drag-and-drop stages (Lead → Contacted → Proposal → Client)
- Call/email logging
- Follow-up reminders
- Basic reporting (leads, conversion rate)

## Tech
- Next.js + Supabase (same stack as mybackyard)
